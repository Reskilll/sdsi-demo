# Brand assets

Put the official **Samsung SDS logo** here as `samsung-sds-logo.png` (a wide PNG, roughly 4:1, transparent background).
The client deck (`src/agents/clientDeck.ts`) uses it automatically on every slide. Without the file, the deck draws a simple
blue wordmark in its place, which is only a stand-in, not the real logo. Use the official file from your brand portal;
this repository does not include it.
