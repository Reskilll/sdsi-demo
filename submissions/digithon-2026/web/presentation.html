Why you can trust it

Models judge. Tools measure. Humans decide.

📏 Real numbers

Speed, accessibility, traffic and technologies are measured by tools. Models only judge design and clarity. Findings carry evidence.

🛡️ Guardrails

The planning model chooses the next step, but code enforces order, retry limits and a step budget. A bad answer falls back to rules.

🔌 Always works

No model key or network? Offline mode still runs end to end. Any past run replays for free.

📓 Fully documented

43 logged decisions, 49 tests, and tagged releases to fall back to: v0.1.0, v0.2.0, v0.2.1.

Talent roster, org skills and pricing constants are labelled sample data until real data is connected.
